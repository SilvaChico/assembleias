# Proposal-code review screenshots

Captured by `npm run test:browser` against an isolated loopback server and in-memory SQLite database. Proposals, counts and generated codes are fictitious. No production credentials, database or room codes were used.

- `vote-entry-mobile.png`: participant entry using “Código da proposta”.
- `proposal-before-vote-mobile.png`: the proposal text and discussion support appear before voting opens.
- `proposal-created-mesa.png`: mesa proposal selector and code available immediately after creation, without room controls.
- `active-vote-mobile.png`: the same proposal and code while voting.
- `closed-result-mobile.png`: final digital, physical and combined counts.
